AUGUSTA Gerüstbau UG – Cloud App V4

V4 ENTHÄLT
- modernes Dashboard
- Kunden- und Rechnungsformular
- automatische Rechnungsnummer
- PDF-Erzeugung auf dem Server
- Upload nach Supabase Storage
- Mailversand mit Resend
- bessere Oberfläche

START
1. ZIP entpacken
2. .env.local.example zu .env.local umbenennen
3. Werte eintragen
4. npm install
5. npm run dev
6. http://localhost:3000 öffnen

BENÖTIGT
- Supabase URL
- Supabase Anon Key
- Supabase Service Role Key
- Resend API Key
- Storage Bucket: customer-documents

TABELLEN
- customers
- invoices
- invoice_items

V4 ist die erste brauchbare Firmen-Basis mit Backend.
